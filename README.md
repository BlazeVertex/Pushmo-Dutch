Pushmo Dutch
A Dutch fan translation of Pushmo for Nintendo 3DS.

Pushmo Dutch is an unofficial fan translation project aiming to make Pushmo (also known as Pullblox in Europe) available in Dutch.
Project status
<details>
<summary>Development status</summary>Work in progress. The translation is still being developed and tested. Files in this repository should not be considered a finished release unless explicitly stated otherwise.
</details>Repository contents
File	Description
orca.msbt	Dutch-translated MSBT message file currently included in the project.


The repository currently focuses on sharing the translation file and documenting the project. More files may be added as the translation progresses.
Applying the translation
The MSBT file is intended for use with the appropriate version of Pushmo and the tools required to modify its game data.

A complete installation guide will not be provided for this project. 
You will need your own legally obtained copy of the game.

Compatibility with specific game regions, revisions, or modding setups has not yet been fully documented. 
Please do not assume that the file work with every version of the game.

Feedback and issues
If you find a mistranslation, spelling mistake, display issue, or technical problem, please open a GitHub Issue and include:
- The affected text or location in the game.
- What you expected to see.
- What appeared instead.
- A screenshot or other useful details, if possible.
